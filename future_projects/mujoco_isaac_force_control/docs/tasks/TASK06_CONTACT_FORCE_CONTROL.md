# Task06：接触与一维 Force Control

## 学习目标

第一次让机器人真正和环境接触。先只做最简单场景：TCP 沿 Z 方向接触水平刚性平面，并保持指定法向力。

## 控制目标

```text
Fz -> Fz_des
```

第一版可用简单 PI/PID 或 admittance-like 外环，不追求复杂模型。

示例：

```text
force_error = Fz_des - Fz
z_ref_dot = Kf * force_error
```

然后由已有阻抗/位置控制器跟踪变化后的 `z_ref`。

## 教学重点

- 接触前不能拿“接触力误差”直接控制；
- 力传感器测量值包含符号和坐标系问题；
- 接触刚度、仿真 timestep、控制增益共同影响振荡；
- 期望力与最大允许力要分开定义。

## 实验

- 5 N / 10 N / 15 N 三组目标；
- 不同接触刚度；
- 不同控制频率；
- 接触建立与退出。

## 验收

- 正确检测 contact；
- 稳态法向力误差可量化；
- 无持续高频振荡；
- 峰值力不超过安全阈值；
- 输出 `Fz(t), z(t), tau(t)`。
