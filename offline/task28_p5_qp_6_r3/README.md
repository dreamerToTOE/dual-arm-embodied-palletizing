# QP-6-R3 original-scene runtime evidence

`runtime_dev.py`, `runtime_dev02.py`, `runtime_dev03.py`, `runtime_dev04.py` are four separately registered development runs. Each starts a new process and fresh anonymous stage, calls the frozen original builder, suppresses only the ROSGraph in memory, keeps original native arm/finger drives, and writes no explicit joint effort or position commands. Run 03 additionally calls the installed wake API once per arm per explicit step, as documented in its preregistration. The result file is written before Kit shutdown. The four runs are already used in this task's budget; do not automatically rerun them.

`audit.py` independently recalculates numerical observations from the raw records. Solver-projected effort is not a calibrated torque sensor; its post-state diagnostic residual is not a source qualification. `approach_audit.py` is a 51-sample maximum offline IK/FCL screen, not a continuous collision proof or an executed path.

`effort_adapter.py` contains a **candidate real Isaac effort sink**, with default disabled ownership, paired prevalidation, original finger drive and applied-input preservation, no position message and post-step gate. Its nominal success branch was tested only with synthetic mock handles and a synthetic test certificate. The scene source was not qualified; the adapter was never activated against Isaac. Its gate callback and persistent journal still require scene-specific runtime integration and verification; it is not production-ready or a validated controller.

Evidence includes first failure, dt, q/dq/M/c/g, actual physical link8 and TCP derived using the verified link8-to-TCP transform, Cube pose, frozen FCL screening, implicit physics initialization caveat, native tool mass reading, skipped cells and prior regressions. `summary.json` is the status index. The 4.5 API documentation and installed source hashes appear in `evidence/api_source_audit.json`. See the Chinese task report for limitations and first failure of every run.
