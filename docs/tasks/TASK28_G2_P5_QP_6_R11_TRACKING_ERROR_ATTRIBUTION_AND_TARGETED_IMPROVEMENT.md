## R10 V10-A 逐时刻归因

R10 V10-A 归档为 210 个 QP 帧，物理步 `183..392`。机器证据见 `evidence/single_variable_diagnostics.json` 和 `evidence/error_decomposition.json`；每帧记录包含目标虚拟位姿、左右实际/参考 TCP、左右隐含物体位姿、相对 TCP、`q/q_ref/qdot/native dq`、QP 状态和残差、力矩分项及努力读回。

峰值发生在 physics step `195`（约 `3.25000017 s`）：

| 分量 | 峰值 | 证据与强度 |
|---|---:|---|
| 实际共同物体误差 | `0.578620 mm` | 直接由实际 TCP 映射到虚拟物体，主观测，强 |
| 实际−参考 FK 动态滞后 | `0.578556 mm` | 实际隐含物体减 `FK(q_ref)`，同一步，主观测，强 |
| 参考轨迹误差 | `0.184352 mm` | `FK(q_ref)` 对目标的直接重算，step 186 达峰；step 195 仅 `0.000417 mm`，次要 |
| 左右相对 TCP 平移误差 | `0.093523 mm` | 直接相对 SE(3) 观测，低于 `0.150 mm`，不是主要来源 |
| QP 硬相对残差 | `1.19756e-10` | 210/210 `QP_OPTIMAL`，远小于运行时 `2e-7` fail-closed 检查 |
| QP common-task 残差 | `1.48274e-9` | 记录值；没有约束激活证据 |
| qdot 峰值 / 限值 | `0.000844635 / 0.12 rad/s` | 约束未触边；lookahead 最小余量 `0.666261 rad`，激活 0/210 |
| native dq 峰值 | `0.0107217403 rad/s` | step 183 ownership 起始，随后关节漂移达到 `0.000998012 rad` |

step `183→195` 的目标虚拟位移只有约 `1.08 µm`，而实际共同误差由约 `0.103 mm` 增至 `0.579 mm`；这支持“继承速度→关节漂移→实际 TCP/物体滞后”的证据链。力矩记录中没有 saturation 或 effort-rate limiting：`P` 峰值约 `0.03281 Nm`，`D` 峰值约 `0.19689 Nm`，gravity 峰值约 `28.00488 Nm`，注册努力速率峰值 `4.40686 Nm/s`。

这是一项有证据等级的归因：动态滞后是支持最强的主要来源；它不把离线回放单独表述为形式因果证明。QP 约束和数值残差是由逐帧日志支持的排除项，而不是未经验证的猜测。
