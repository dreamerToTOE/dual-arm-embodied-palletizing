# Task 03 — B-A-C 放置可执行性

## 状态

✅ **已完成 — 已验证“箱体几何可放，但二指夹爪无法完成密集垂直放置”**

Task 03 用于验证：

> **目标箱 A 的几何体能够放入目标空位，并不代表携带 A 的机械臂末端执行器也能完成插入、释放和退出。**

## 1. 实验场景

```text
A size   = 30 × 30 × 30 mm
A target = (0.65, -0.15, 0.065) m

B size   = 30 × 30 × 30 mm
B center = (0.65, -0.115, 0.065) m

C size   = 30 × 30 × 30 mm
C center = (0.65, -0.185, 0.065) m
```

B/C 内侧净间距：

```text
d_BC = 40 mm
```

A 宽度：

```text
w_A = 30 mm
```

因此：

```text
d_BC > w_A
```

A 本体几何上可以放入。

## 2. 第一轮问题：MoveIt 漏检 finger 碰撞

第一轮曾出现：

```text
C_insert = PASS
Cartesian fraction = 1.0000
```

但 Isaac 中真实 finger 已与 B/C 碰撞。

原因是 MoveIt 规划 RobotState 只写入 `fr3_arm` 七个关节，没有同步：

```text
fr3_finger_joint1
fr3_finger_joint2
```

修复后，携物阶段显式使用真实闭合 finger state，MoveIt 可以正确反映二指夹爪横向包络。

## 3. 最终验证

修正 MoveIt finger state 后，在同一 B-A-C 场景重新运行：

```text
C_reach = PASS
C_insert = FAIL
```

因此最终验证：

```text
A 本体几何可放
但二指夹爪的横向扫掠包络与 B/C 干涉
```

即：

```text
几何可放置 ≠ 机器人可执行放置
```

## 4. 工程结论

Task 03 暴露的是普通二指侧夹末端在高密度箱体码垛中的结构性问题。

在实际码垛中，目标箱右侧、后侧甚至多侧已经有码好的箱体非常常见。此时：

```text
仅改变 yaw
仅改变放置顺序
为箱体永久留 finger 缝隙
```

都不能作为通用解决方案。

“放下后再用刚性位置控制推紧箱体”也不作为主路线，因为接触力会通过相邻箱体向垛堆传播，容易引入新的稳定性与接触控制问题。

## 5. 后续末端执行器决策

后续工程统一改用：

> **固定顶部吸附式末端执行器。**

左右 FR3 始终使用同一种顶部吸盘，不根据松 / 紧协调切换工具。

### 松协调

```text
一台机械臂
↓
顶部单吸盘
↓
一个小箱体
```

两台机械臂可分别搬运不同小箱体。

### 紧协调

```text
Left suction          Right suction
      ↓                    ↓
┌─────────────────────────────┐
│          Large Box          │
└─────────────────────────────┘
```

两台机械臂在同一个大箱体**上表面两个分离吸附点**共同吊运。

这样大箱的最终码放仍然从顶部下降和释放，不需要在箱体左右侧预留夹爪退出空间。
