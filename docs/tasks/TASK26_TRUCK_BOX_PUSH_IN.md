## 1. 目标

在桌面（顶面 `z=0.200`）上放一个三面围墙的车厢，用双臂侧面吸盘把 4 件 `0.120` 立方
逐件**从装料口水平推入**车厢第一层，每排先推里格、再推外格。

- 车厢：三面围墙 + 顶上无墙，装料口 **−X 面**（用户指定），推入方向 **+X**。
- **车厢放在 +X 侧、Y 向居中**（对称轴 `y=0`，两臂基座 ±0.60 到两排等距）。
- **两个机械臂各一条 X 向导轨**，基座沿 X 平移（推入方向与导轨轴一致，持件臂能跟着
  Cube 往车厢深处走）。
- 桌面 / 供料槽 / Cube 初始位按"舒适码垛"重摆（见下），接触高度 `z=0.260` 保持已验收值。

### 开口方向（已定，勿再反推）

用户 2026-09-21 明确指定**开口是 −X 面**。早先我用视口相机位姿反推屏幕方向，把 −X 与
+Y 弄混过两次。**结论：车厢方向类问题一律直接问用户，不要用截图反推。**

## 2. 布局总览（本轮定稿）

| 项 | 值 |
|---|---|
| 机械臂基座 | Y 固定 `±0.60`，X 沿导轨 `[0.45, 0.85]`，静止位 **`x=0.65`**（必须与共用 URDF 的 `world_to_*_fr3` 固定关节一致，否则执行器规划与 Isaac 实际基座错位 0.20 m） |
| 导轨 | **X 向**，两臂各一条，行程 0.40 m（静止位 0.65 两侧 ±0.20，对称） |
| 桌面 | 中心 `(0.55, 0, 0.10)`，尺寸 `1.50 × 0.80 × 0.20`（加宽） |
| 车厢 | 内腔 `x∈[0.66, 0.91]`、`y∈[-0.125, 0.125]`（Y 居中），开口 −X |
| 格位 | 深 `x=0.840`、浅 `x=0.720`；两排 `y=+0.065 / −0.065` |
| 预推位 | `x=0.540`，y 与该排相同（装料口外 120 mm） |
| 供料槽 | `A=(0.50, 0.00)`、`B=(0.35, 0.00)`（**中轴线 y=0**、靠近基座） |

推入方向 +X，每排**先深格后浅格**（浅格先落会挡住通往深格的直推通道）。

### 供料槽为什么必须在中轴线 y=0 且靠近基座

双臂共同夹取要求**两臂都能到同一件**。放在 `(0.28, ±0.10)` 时右臂要到
`TCP=(0.28, −0.039)`，从基座 `(0.65, 0.60)` 是 **0.74 m** 斜向长臂 → RRT 8 候选全部
超时，连放置链路都过不去。放到中轴线 `y=0` 且 `x=0.50/0.35` 后两臂对称、最大伸展约
**0.60 m**，通过。

### 推入必须用 -X 面持件（关键）

侧吸工具在杯面后方伸出 **155 mm**，而车厢内腔只有 0.25 宽、两排各 0.12。若继续用
±Y 面持件沿 +X 推入，工具会伸进车厢并撞 ±Y 墙或另一排已落稳的 Cube。改持 **-X 面
（装料口那面）** 后，整个工具留在车厢外侧，往里推 +X 不碰任何墙 —— 这是本车厢唯一
可行的推入持件面。

推入姿态 `pushPose`：quaternion `(x,y,z,w)=(1,0,0,0)` = 绕世界 +X 转 180°，
杯面法向 `+X`（穿进 Cube）、`+Z` 仍指向下，与 `sidePose` 的下压约定一致。
**该姿态尚未通过 IK/FCL 验证**（换位段 RRT 目前无解），下一步要先单独查它的 IK。

### 推入臂必须按排选取

车厢居中后，每排到**对面那条臂**的横向距离是 0.665 m。左臂去推 `y=+0.065` 那排要
0.69 m → 换位 RRT 全超时；每臂只推自己那一侧是约 0.57 m（已按此实现）。

| 次序 | Cube | 预推位 | 格位 |
|---|---|---|---|
| 1 | Cube_01（批1） | (0.540, +0.065) | (0.840, +0.065) 深 |
| 2 | Cube_02（批1） | (0.540, +0.065) | (0.720, +0.065) 浅 |
| 3 | Cube_03（批2） | (0.540, −0.065) | (0.840, −0.065) 深 |
| 4 | Cube_04（批2） | (0.540, −0.065) | (0.720, −0.065) 浅 |

### 内腔净空

内腔 0.250 = 2 × 0.120 货物外廓 + 每侧 5 mm（零净空会让 Cube 与墙、Cube 与 Cube 直接
贴合）。+X 墙内表面 0.910、深格 Cube 外表面 0.900 → 10 mm；±Y 墙内表面 `±0.125`，两排
外表面各留 5 mm。

## 3. 导轨（第七轴，X 向）

用户要求**导轨沿 ±X 轴**、机器人沿 X 移动。好处：推入方向也是 +X，持件臂可以随 Cube
往车厢深处走，深格不再是固定基座下的极限拉伸；左/右臂行程对称（`[0.25, 0.70]`）。

与上一版 Y 向导轨相比，X 向更干净：

- 整条导轨都在桌面两侧（`y=±0.60`，在桌面 `y∈[-0.40,0.40]` 之外），**不会像 Y 向那样
  伸到桌面下方**，也不存在"肩部外壳压进桌面"的内向行程上限（肩部在 Y 向突出、与 X 行程
  正交）→ 行程可以对称。
- 滑台顶面 `z=0.000`，**不改变基座高度**。

### 实现（沿用上一版已验证机制）

- 导轨件为**纯视觉件**（两条导轨条沿 X + 两端挡块 + 滑台），无碰撞体。
- bridge：`/task26/{side}/rail_command`（目标 X）→ `rail_state`
  `[target, arrived, measured, x_min, x_max]`。
- **USD + Fabric 同值双写**（Isaac 4.5 渲染读 USD、物理读 Fabric，只写一套会互相矛盾）。
- 两道联锁不变：吸盘夹紧 / 最近 1 s 内有关节命令时拒绝动轨。

### 通用几何规律（与布局无关，沿用早先实测）

- 侧吸 L 型支架 TCP 相对法兰侧向偏置 **155 mm**；双臂紧协调放置要求 Cube 中心两侧各留
  `60 + 1 + 155 = 216 mm` 通道。
- 机械臂低位姿态时前臂 z 区间约 0.42–0.50，伸到该高度的墙可能挡下探（本布局墙高 0.250
  不影响，但仍需预检确认）。
- 双臂共同搬运必须原子下发（`DUAL_SYNC_FRAME_ID = "task26_dual_sync"`）。
- 零命令预检（`planning_only:=true`）不得发布 joint / suction 命令。

### Isaac 4.5 的坑（已写进 skill，务必遵守）

1. physics callback 静默吞异常 → 用 `try/except + traceback` 包一层（限流）。
2. 渲染读 USD / 物理读 Fabric，平移整条臂要**同值同时写两处**。
3. 视口相机不接受 prim 写入，取景用 `frame_viewport_prims`。
4. `capture_viewport_to_file` 无 `.done()`，Timeline 停止时可能返回重复帧，先 Play 再截。
