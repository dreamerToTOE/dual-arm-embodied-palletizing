# Task26：货车「车厢」三面围墙 + 预推入位（第一层 4 件）

状态：🟡 几何设计已完成并用 MoveIt 实测可达性；场景与执行器待实现。

本轮暂停 Task25 的收尾，按用户要求改工作环境：把 Cube 码进一个**顶上无墙的车厢**。
车厢三面围墙，双臂的侧吸紧协调在格内无法实施，因此改为
**「双臂紧密协调放到预推位 → 单臂吸盘沿 +Y 推入格内」**。本轮只做第一层 4 件。

## 车厢尺寸（按现有场景推得）

现有场景基线：桌面顶面 `z=0.200`、桌面 `x∈[-0.050,1.150]`、`y∈[-0.400,0.400]`、
基座 `(0.650,∓0.600,0)`、Cube `0.120 m`、L 型支架 TCP 侧向偏置 `155 mm`。
**底板直接沿用桌面**（不抬高），因此 Cube 中心仍保持已验收的 `z=0.260`。

```text
车厢内部：x ∈ [0.640, 0.880]  (0.240 m = 2 列，列心 x = 0.700 / 0.820)
          y ∈ [-0.030, 0.210] (0.240 m = 2 排，排心 y = +0.030 / +0.150)

墙体：厚 0.020 m、高 0.250 m（z 0.200 → 0.450）。按「至少两层」定：
      两层 Cube 共 0.240 m，墙高取 0.250 m 才能约束住第二层
      左侧墙  x ∈ [0.620, 0.640]，y ∈ [-0.030, 0.230]
      右侧墙  x ∈ [0.880, 0.900]，y ∈ [-0.030, 0.230]
      后墙    y ∈ [0.210, 0.230]，x ∈ [0.620, 0.900]
开口：-Y 方向（装料口）+ 顶部完全无墙（机械臂从上方进出）
```

第一层 4 格（`z = 0.260`）：

```text
远排 y=+0.150：  (0.700, +0.150)   (0.820, +0.150)
近排 y=+0.030：  (0.700, +0.030)   (0.820, +0.030)
```

## 预推位

```text
C1 预推位：(0.700, -0.150, 0.260)
C2 预推位：(0.820, -0.150, 0.260)
```

即**装料口外 180 mm**，与车厢内部近排（`y=+0.030`）的中心距为 `0.180 m`。

为什么是 `y=-0.150`：

- 预推位要由**双臂紧协调**放置，因此它两侧必须留出 L 型支架的回旋通道
  （Cube 中心两侧各 `60 + 1 + 155 = 216 mm`）。
- 车厢最靠近装料口的一排必须落在该通道之外：`y_排 ≥ y_预推 + 216 + 60 = +0.126`，
  取 `+0.150`（也正好是 Task25 里已物理验收过的行）。
- 同时 `y=-0.150` 本身就是 Task25 已验收过的近排目标行，双臂可达性有实物证据。

## 推入动作（单臂、左臂）

左臂吸盘的杯面朝向世界 `+Y`，正好可以对准 Cube 的 `-Y` 面：

```text
左臂 TCP = (x, cube_y - 0.061, 0.260)      # cube 中心高度，不做抬升
吸盘对准 -Y 面 → SUCTION ON（保持吸附）
显式 +Y 直线：cube_y  -0.150 → +0.030（近排，推程 180 mm）
                      -0.150 → +0.150（远排，推程 300 mm）
TCP        y：        -0.211 → -0.031 / +0.089
SUCTION OFF → 竖直抬升退出（车厢无顶，直接从上方退出）
```

推程终点由命令位置给出，最终位置仍用 Isaac Ground Truth 门限（≤ 10 mm）验收；
后墙与已落稳的同类件同时充当天然的机械限位。

## 执行顺序（几何强制）

**同一列内必须先做远排、后做近排**：

- 推**远排**时，左臂支架（在 TCP 后方 155 mm）会扫过 `y ∈ [cube_y-0.216, cube_y-0.061]`。
  若近排已经落稳（`y=+0.030`，占 `y ∈ [-0.030,+0.090]`，`z 0.200–0.320`），
  支架在推程末段会与它重叠 → 真实碰撞。
- 推**近排**时，支架在 `y ∈ [-0.186,-0.031]`，完全在装料口一侧，即使远排已落稳也不干涉。

因此每列的次序固定为 `远排 → 近排`；两列之间互不干涉（X 向净距 25 mm 以上）。

```text
C1 远排：放置预推位 → 推入 → 退出
C1 近排：放置预推位 → 推入 → 退出
C2 远排：放置预推位 → 推入 → 退出
C2 近排：放置预推位 → 推入 → 退出
```

预推位 (0.820,-0.150) 双臂 / 运输高度 0.540   左 OK  右 OK
预推位 (0.820,-0.150) 双臂 / 释放高度 0.280   左 OK  右 OK
左臂推入 x=0.700：预推位 / 近排 / 远排          OK / OK / OK

净空（按几何推算，已修正到同一坐标系）：

- 工具在 X 向的包络为 ±0.035 m。两列的 Cube 中心距 0.120 m，两侧墙内表面分别在
  `x=0.640` 与 `x=0.880`：工具边缘到墙内表面各留 **25 mm**。
- 推入过程中工具本体全部位于 Cube 的 `-Y` 侧（装料口一侧），不会进入已落稳格位。
- 车厢无顶：推入结束后单臂竖直退出，不需要任何绕行。

零命令预检（`max_batches:=2 -p planning_only:=true`）目前的进展与阻塞：

- 左臂高位接近 → 外侧下降 → 接触：**通过**（8 候选，fraction 1.0000，离线 0.003 mm）
- 右臂高位接近：**通过**
- 右臂「低位外侧」接近：**失败** —— 8 候选 × 3 批 × 20 s 全部超时；改用等价的

  两者共同指向同一原因：**左臂正停在接触位、车厢又在旁边，右臂低位姿态的有效自由空间
  几乎被吃光**。

### 本轮实测到的五条硬几何结论（全部有数据）

1. **运输高度可达性**：右臂腕部位置 = `cube_y + 216 mm`；在 z=0.540 的运输高度上，
   预推位取 `y=-0.150` 时腕部落在 `+0.066`、肩距 0.72 m，已贴到 0.70 m 臂链边界，
   实测四种步长的笛卡尔抬升轨迹全部失真（离线 1.2 m）而被拒 → 预推位北移到 `y=-0.120`。
2. **前臂与墙高冲突**：右臂低位姿态时前臂 link5/link6 的 z 在 **0.42–0.50** 扫过车厢口，
   因此任何 ≥0.200 高的墙都会挡住它。实测 0.250 高时「纯 Z 下降」fraction 掉到 0.61
   （任何宽度都一样）。为此第一层墙高降到 **0.150**（顶面 0.350，前臂净空 ≥70 mm）。
3. **前臂与侧墙的 X 向净空**：实测右臂低位前臂在 `x≈0.61–0.73`，因此侧墙内表面必须
   退到 0.560/0.960（车厢内净空 0.400×0.290，货物 0.240×0.240 靠后墙放）。
4. **右臂外侧偏移必须很小**：把 `x=0.700, z=0.260` 沿 y 扫一遍，右臂在 `y <= -0.039`
   时各解支都有效，从 `y >= -0.019` 起出现 link5/link6 撞墙；因此右臂用
   `kRightPreContactOffsetY = 0.020`（左臂仍 0.100）。
5. **左臂自碰**：左臂在预推位的外侧低位姿态（`y=-0.281, z=0.260`）会出现
   `left_fr3_link1 <-> left_fr3_link7` 自碰，靠 8 候选筛选规避（已在预检中生效）。

### 结论与建议

第 3 条阻塞说明：**「双臂在紧贴车厢口的预推位放置」这件事本身就落在工作空间的边缘**
——右臂要跨过桌面中线去够 Cube 的 +Y 面，同时还要绕开车厢和停在接触位的左臂。

两个出口：

- **推荐：加 Y 向滑轨（第七轴）**。基座南移 ~0.20–0.30 m 后，
  ① 预推位可以放到 `y≈-0.30` 的真正开阔区，双臂放置不再与车厢耦合；
  ② 第二层必然需要它（上层运输高度只会更高，右臂更够不到）。
  代价：基座成为关节变量，Task24/Task25 的全部位姿验收基线需重验（见前面「滑轨评估」节）。
- 不加滑轨的话，可行窗口只有约 5 mm（`y_pre ≈ -0.125`：运输侧肩距 0.583 m 刚够、
  低位外侧 `y=-0.044` 刚在有效边界内），工程上不可取。

## 滑轨（第七轴）评估

用户提出在机器人下面加滑轨以便安排车厢位置。结论：**对第一层没有必要，对第二层有价值。**

约束的性质不同：

- 第一层真正的约束是 **L 型支架 155 mm 侧向偏置带来的 216 mm 通道**——它由 TCP 位姿与
  工具的固定偏置决定，**与基座位置无关**，滑轨沿 Y 移动不能放宽它。
- 沿 X 的滑轨能扩展 X 向够得着的范围，但本轮瓶颈在 Y 而不是 X。
- 本设计已用 MoveIt 实测：预推位与三个推入目标在当前基座下全部可达（见上面实测表），
  因此第一层不需要滑轨。
- 滑轨真正会帮上忙的地方：① 车厢可放到更真实的位置（桌面外的货车/托盘）；
  ② 第二层——上层 Cube 的进深与高度都会明显更紧，第七轴能直接扩展可操作域。

代价（必须提前知道）：

- 基座从固定变为关节变量后，**Task24 / Task25 的全部位姿验收基线作废**：所有 IK、可达性、
  同步 FCL 与已验收靶姿都要在新基座下重新验证。
- Isaac 需要把根关节改成 prismatic 轴，MoveIt 侧 SRDF/URDF 与 launch 都要同步改；
  滑轨自身的行程、限位、标定也要建模。

建议：第一层先不加；若要做，作为独立一步（例如 Task27）单独实现与验收，不要和车厢几何混在一起。

## 推入方式：吸附后推（A） vs 纯杯面顶推（B）

| 维度 | A：吸附后推 | B：不吸附纯顶推 |
|---|---|---|
| 传力 | 通过吸附建立的 D6 六维约束，本质是「带着 Cube 走」 | 只能传接触法向压紧力，单向 |
| Cube 约束 | 6 自由度全约束，滑行不偏转 | 仅靠接触摩擦/几何，可能绕竖轴转动或侧滑 |
| 落位精度 | 由 TCP 直接决定（需补偿 D6 软性形变约 0.6 mm） | 由压深+摩擦决定，精度与重复性更差 |
| 所需力 | 只需覆盖桌面滑动摩擦 `μmg ≈ 5.9 N` | 由过压产生，压深与法向力无直接对应 |
| 判据 | 直接复用贴合门限 / SUCTION ON-OFF 确认 / GT 回写 | 需新建「是否贴上」的压深或力矩判据 |
| 主要风险 | 吸附建立瞬间推偏（已有 1 mm 间隙 + 2 mm 门限防）；卡死时力无上限 | 失接触即失效；Cube 可偏转；精度不稳 |
| 栈改动 | 现有链路全复用，只需加力/跟踪监督 | 需新增接触判据与压深规定 |

**变体**：A 之后先把 Cube 抬 2 mm 再 +Y，可使桌面摩擦归零、力与抖动最小，但会失去
「贴墙自对齐」——滑动推时 Cube 沿车厢侧墙走，落位由墙兜底。

**结论：第一层用 A（吸附后推）+ 力/跟踪监督**，理由是复用全部已验收门禁、精度最好、
滑动推天然带贴墙自对齐；B 保留为「吸盘在车厢内贴不上」时的后备方案。
注意两者都不改变「同列必须先远排后近排」的几何约束——那来自工具外形，与接触方式无关。

## 推入的接触力与力控

**第一层方案：位置控制 + 力/跟踪监督（不引入新的控制层）。**

- 推进做成 1 mm 步进；每步读关节力矩（必要时读接触力）与 Cube 的 Isaac Ground Truth。
- 触发条件（任一）即停止推进并沿 -Y 回退到安全位：① 力矩/接触力超过阈值；
  ② TCP 在推进而 Cube Ground Truth 不再前进（卡住或顶死）。
- 这样不需要改动现有「关节到位 + 同步 FCL」门禁，也不需要 effort 通道。

为什么第一层必须至少有力上限：现在吸盘用的是 `stiffness=1e4 / damping=1e3`、断裂阈值 `1e6`，
所以**位置命令持续前推时接触力没有上限**，撞到后墙或已落稳件时会硬顶。力上限 + 越限即停
属于安全项，不是可选项。

**后续（真力控）：** bridge 的 `ArticulationAction` 支持 effort 通道，可以另做一层笛卡尔阻抗
控制。FR3 真机本来就有这个能力（`franka_ros2` 的 Cartesian impedance 示例），所以路线是通的；
但它会绕过现在的关节到位与同步 FCL 门禁，需要作为独立任务单独设计与验收。
