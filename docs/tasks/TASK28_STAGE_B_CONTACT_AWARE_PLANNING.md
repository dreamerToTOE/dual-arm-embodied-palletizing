## 工艺分界

原 `planSideCompaction` 先规划高位接近，再到距离 Cube 侧面 1 mm 的低位目标；它随后将目标增加 4 mm 超程，并在侧压段从 MoveIt world 移除 Cube。对贴墙名义姿态，这使辅助吸杯的目标进入 Cube 约 3 mm：该目标不能作为完整无接触碰撞场景中的自由空间目标。原 B0 安全中止保留，且现在使用可单独测试的 `legacySidePressAllowed` 检查；B0 不会进入旧的 Cube 移除分支，非 B0 的旧行为不变。

本轮将工艺明确分为：

1. **自由空间接近 APPROACH**：Cube、桌面、三面墙和双臂均在碰撞场景中；辅助臂到 Cube 上方高位，推入臂保持记录的关节状态。
2. **预接触对齐 ALIGN**：辅助臂在 Cube −Y 面外侧沿竖直线下降，末端法向对准 Cube，停在正间隙目标；仍对完整碰撞场景逐点检查。
3. **接触建立 CONTACT**：未来在确认观测有效、力传感/估计链健康及允许接触条件后，以受约束的速度或顺应量接近；不把规划器内的穿入点当作自由空间目标。
4. **受控侧推 FORCE_RAMP / PUSH**：未来使用经过独立验证的接触力闭环，限制关节力矩、力矩变化率、速度、加速度和位姿，并监测丢失接触、卡滞和过力。
5. **接触终止与退避 SEATED / EXIT**：未来确认间隙、承托和低速后卸载、解除所需吸附，再沿已验证的清障路径退出，复核 Cube 稳定性。

前三段中的运动边界不代表已经物理建立接触；本工单只生成并验证前两段离线轨迹。

## 分层架构提案

已批准的方向包括 B0 吸附辅助位置轨迹推送与 torque-QP 执行、未来 B1 无吸附接触及经验证力反馈后的混合力/位置研究、计划中的下层接触状态机，以及可能的上层选择器。以下更具体的状态顺序、观测和转换是本工单的**新设计提案**，尚未实现；特别是把 ALIGN 放在 CONTACT 之前，并允许后续因偏差再进入 ALIGN，细节仍待验证。

**上层策略选择器（提案）**：根据任务几何、吸附与支持状态、接触观测质量和可用约束，选择吸附辅助推送、无吸附接触推送、可选第二臂侧向辅助或恢复策略。它应输出模式/目标及可解释原因，并只在下层确认安全退出和观测有效时切换；切换规则尚未定稿或实现。

| 下层状态 | 必要观测 | 计划输出与转换 / 互锁 |
|---|---|---|
| APPROACH | 同步 Cube/双臂位姿，完整场景、碰撞和关节状态 | 自由空间轨迹；路径与限位通过且到达高位后转 ALIGN；观测失效或碰撞则停。 |
| ALIGN | 侧面法向、TCP/Cube 位姿和正间隙 | 沿验证的自由空间路径对齐；到达非穿入预接触位后，只有力观测链和接触模式准备完成才可转 CONTACT。 |
| CONTACT | 合法法向、有效力源、位置/速度和支持状态 | 受限趋近；接触证据持续成立后转 FORCE_RAMP；无观测、超时、过力或意外碰撞则停止或恢复。 |
| FORCE_RAMP | 标定力、同步状态、关节力矩/速度和约束 | 有界力参考或顺应位移渐增；稳定达到待定范围后转 PUSH；过力或失联立即卸载。 |
| PUSH | 实测/经验证力、Cube 位移、接触保持、限位与 QP 状态 | 法向受控、切向受约束推送；目标到达转 SEATED，偏差可返回 ALIGN，卡滞或丢接触转 JAM_RECOVERY。 |
| JAM_RECOVERY | 速度、力、间隙、支持与吸附状态 | 冻结/卸载并择已验证退避或重新对齐；恢复次数与阈值待定，条件不明保持停止。 |
| SEATED | 深墙/侧墙间隙、支持、低速及接触力 | 验收后卸载并确认必要释放；不满足继续保持或恢复，不能用目标位置替代实测。 |
| EXIT | 已确认释放、Cube 稳定状态、完整障碍和双臂状态 | 沿验证路径清障，复核支持与稳定；非预期接触或观测失效停止。 |
